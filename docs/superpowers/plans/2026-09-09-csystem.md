# CSystem Implementation Plan

> **For agentic workers:** Execute inline in this session (user requested immediate build). Checkbox steps track progress.

**Goal:** Build greenfield CSystem web app: login, shops CRUD, per-module Y/E/N statuses, reports, login/audit logs — data in `BD_CSystem` on tvsdb2.

**Architecture:** New folder `csystem/` with Node HTTP server + vanilla SPA. ODBC to SQL Server. Session cookies. No dependency on Customer Profile app code.

**Tech Stack:** Node ≥ 18, `odbc`, `crypto.scrypt` password hashing, SQL Server `BD_CSystem`

## Global Constraints

- Database: `tvsdb2.thanvasupos.com,28914` / `BD_CSystem` only
- Status values exactly: Y | E | N
- Service catalog + business types per `docs/superpowers/specs/2026-09-09-csystem-design.md`
- Secrets in `csystem/.env` (gitignored); never commit passwords
- New codebase under `csystem/` — do not reuse Customer Profile UI
